# Security Policy

CoreTech Talents is a privately maintained platform. This repository does not follow a
public versioning/release model, so the standard "Supported Versions" table doesn't apply -
only the current `main` branch, which is what's deployed live, is maintained and patched.

## Reporting a Vulnerability

If you discover a security vulnerability in CoreTech Talents (coretechtalents.com) or this
codebase, please report it responsibly:

- **Email:** coretechtalents@outlook.com
- Please include: a description of the issue, steps to reproduce it, and its potential
  impact, if known.
- Please do not publicly disclose the vulnerability (e.g. via a public GitHub issue) until
  it has been addressed.

**What to expect:**
- Acknowledgement of your report within a reasonable timeframe
- An update once the issue has been investigated
- Notification once a fix has been deployed

## Scope

This applies to:
- The CoreTech Talents backend API (Railway)
- The CoreTech Talents frontend (coretechtalents.com, Vercel)
- The associated PostgreSQL database, insofar as vulnerabilities are reachable through the
  application itself (not infrastructure-level issues with Railway/Vercel as providers,
  which should be reported to them directly)

## Data protection

CoreTech Talents processes personal data of candidates and recruiters in accordance with
India's Digital Personal Data Protection Act, 2023. See our
[Privacy Policy](https://www.coretechtalents.com/privacy-policy) for details on data
handling, and our Grievance Officer contact for data-related concerns
(coretechtalents@outlook.com).
